# CAD Mesh Reconstruction

This panel wraps the bundled CAD Mesh Tool 0.4.1 method A. It does not use Geometry Nodes, a network service, or an LLM. The original object and its mesh are read-only. The addon never saves the current `.blend` automatically.

## Auto and Power user

The two buttons at the top display only the selected mode's controls. New scenes start in **Auto**; saved scenes with older CAD settings migrate to **Power user**. Switching modes preserves the independent Auto and manual reconstruction settings.

**Auto** has an **Objective** and four inputs: Hole Detail, Perimeter Clearance, General Deviation and Hole Deviation (zero inherits General Deviation). **Analyze & Reconstruct** captures the selected objects or input collection and creates a fresh output collection outside the input. Hidden manual switches are ignored. The external worker separates independent solids and chooses normal or guarded reconstruction for each. Invalid source solids remain blocked without stopping other solids.

Each solid compares at most four immutable variants: preserved curve segmentation with planar cleanup, full reconstruction without loops, full reconstruction with loops when applicable, and a holes-only fallback when full reconstruction fails or leaves regions. The planar baseline runs first so an interrupted curve search can retain a validated result. Smaller independent bodies run before larger ones, preserving their original solid IDs for results and retries. Every variant must pass full validation after cleanup. With the default objective **Lightweight** the winner has the fewest final triangles; ties favor more simplified regions, then more reconstructed regions. With **Editable** the winner retains the fewest regions, then has the most support loops around holes, and only then the Lightweight order decides; this usually keeps the `full_loops` variant whenever its loops validate. The objective changes only the choice between already validated variants, never a tolerance or check. Tolerances and recovery limits are not increased. Results record the chosen strategy, actual triangle counts, rebuilt/simplified/retained regions and loops. Deliberately omitting loops in Auto alone does not cause REVIEW; retained regions and source defects still do. Auto is not a guarantee of complete reconstruction.

**Power user** retains the manual operations, Separate Solids, curve segmentation and normal controls, plus separate Analyze and Reconstruct buttons. Analysis recommendations change settings only through **Use Suggested Settings**. Requested perimeter loops that cannot be created still cause REVIEW.

**Max. Worker Time (min)** applies to reconstruction and separate analysis. Default **10 minutes**; **0** disables the limit. In Auto it is under collapsed **Run Settings**, alongside the run folder and worker count (default four). The limit covers one external process: all variants of one Auto solid, or one Power user work item.

Auto schedules **one worker process per independent solid**. When a source is captured, its solids are partitioned once on the main thread from the same snapshot the workers read; every solid becomes its own queued work item with its own result row, sharing one immutable `source.json` (a hard link where the file system allows it). A large assembly therefore uses every worker slot instead of running its solids one after another. Single-solid sources behave exactly as before. A retry of one solid runs only that solid. Expired processes are stopped and queued work continues. Completed results remain available. If an Auto search has already produced a fully validated variant, its best completed candidate is retained as REVIEW with an explicit time-limit explanation; unfinished solids are marked failed. Timeout metadata is saved separately without changing completed variant artifacts. This is a worker deadline, not a deadline for the whole batch or main-thread capture/import.

Cancel and unexpected worker exits also preserve the best fully validated completed variant of an interrupted Auto search as REVIEW. Cancel removes unstarted work; unexpected exits mark unfinished solids failed. Progress publication remains atomic and briefly retries Windows reader-sharing conflicts, preserving the previous checkpoint if publication cannot complete.

## Manual workflow details

Choose **Collection** to process every distinct mesh in the input collection and its children. Results go below the chosen output collection, into a branch for that input collection and shared `PASS`, `REVIEW`, and `FAIL` status collections. Choose **Selected Objects** to process selected meshes and link each result beside its source. Previous results remain available. An earlier CAD output can deliberately be selected, or its collection chosen as a later input; it is never automatically fed into the next run. The current output collection cannot be inside the current input collection. Set a persistent Run Folder before starting; for an unsaved `.blend`, use an absolute path.

**Analyze** runs a cancelable, read-only analysis in separate Blender processes (up to four). It reports edge-connected solids, topology, source intersection pairs, detected holes/bends and target hole segments. On intersection-free inputs it screens the current settings and, where needed, a bounded set of alternatives: holes with bends kept, holes without support loops, and contour preservation. Checkpoint screening uses 750 area samples plus all vertices, edge midpoints and triangle centroids; it is advisory and does not replace full reconstruction validation or final cleanup. **Use Suggested Settings** copies the suggested switches to the shared controls; select the corresponding source before running them. Source fingerprints invalidate stale recommendations. Expanded notes provide **Analysis Files** for exact checks and intersection pairs. An unsaved scene can be analyzed using temporary storage without saving it. **Reconstruct** prepares immutable inputs and external workers. The first worker step checks source intersections before spending time in feature recovery. A source with intersecting surfaces is rejected with an actionable source-geometry message. **Concurrent Workers** controls reconstruction processes (1-16, default four); eight or more still require the existing RAM confirmation. Cancel stops active workers and discards queued work. Preparation/import stays on the main thread, and sources are never edited or saved.

**Automatic guarded strategy:** each input is checked independently. Closed, consistently wound meshes with non-manifold junctions automatically use guarded reconstruction; the separate Try Non-Manifold button has been removed. Open boundaries, duplicate faces and inconsistent winding remain blockers. Guarded workers preserve the original junctions and their dependent source patches exactly, skip conflicting features, and label changed results PARTIAL / REVIEW with CAD_Skipped. This preserves existing defects rather than repairing them; intersection checks remain mandatory. Healthy objects in the same batch use normal reconstruction.

**Circular Holes / Detail:** the adjacent slider multiplies the previous hole segment target. 1.0 retains the old target; lower values request coarser holes and higher values request finer holes, capped by existing source segmentation. The factor applies only to circular holes, not bends or outer cylinders. **Hole Deviation (mm)** sets an independent approximation limit for circular-hole contours and their local rim neighborhood; zero inherits the general Deviation Limit. A coarse factor is clamped to the minimum segmentation that fits that budget (at least three segments). General surface samples outside the hole rim still use the general deviation limit. Keep Curve Segments takes precedence and disables these controls. Reports record both the requested factor and actual segment targets.

**Separate Solids** is explicit and off by default. It partitions edge-connected shells, including shells meeting at isolated vertices. At edges shared by more than two faces it can also extract a shell when its existing faces independently form a closed, consistently wound manifold. A measured planar interface may be reused in two outputs with opposite orientations only when its exact boundary matches two larger open shells and closes both as oriented manifolds. The interface uses existing faces and coordinates; it is recorded in source-face mappings, and each output is validated independently. Ambiguous open patches remain connected; no weld or Boolean union is performed. Each solid gets its own worker, output, validation and result row, while the complete original source fingerprint is checked for every import. Intersections between different solids are retained as assembly relationships rather than certified as one valid united mesh. Any internal intersections or invalid topology in a solid still prevent that solid from producing an output. This allows healthy solids to complete even if another one fails. Analysis uses the same partition and can recommend this option when it finds intersecting independent bodies.

Long open cylinders with a noisy initial axis estimate can refine that axis from two independently measured parallel boundary rails. The refinement must improve the radial fit to micron accuracy, and the complete reconstructed mesh still passes the ordinary topology, intersection and deviation checks.

Completed cylinder support is rechecked for closure: a missing sector that is recovered becomes a closed hole or outer cylinder, with a matching segment count. Flat walls whose corners happen to fit a circle are rejected when their facet normals disagree with the proposed radial side. Trimmed bends use measured boundary paths, including axial steps and intermediate rail vertices; constrained triangulation avoids zero-area n-gon triangles while retaining those shared edges. When perimeter loops are disabled, adjacent holes reserve their actual contours rather than room for unrequested support squares. With loops enabled, planning first reserves future support rings; if that fails, it retries against actual neighboring contours and already created rings. Every resulting ring still passes the usual clearance, quality and full geometry checks. A circular hole for which no support ring fits may use a validated direct join, explicitly reported as a missing requested loop and partial REVIEW.

Reusing an editable result may expose an invalid cached n-gon tessellation along a nearly collinear edge. Capture can replace only the reference triangles of a planar n-gon with constrained triangles, preserving every original vertex, polygon boundary and source fingerprint. The affected polygon IDs are recorded in `source_triangulation_repaired_faces`. Actual source intersections still block reconstruction, and all final geometry checks remain mandatory.

Exact zero-area triangular strips can be repaired on the worker's private copy by sewing collinear edge intervals with existing vertices. This requires a closed oriented independent solid, a single measured line, nonconflicting neighboring triangles and unchanged Euler topology. No vertex is moved or welded. Sharp/protected boundaries and nearly zero but nonzero surfaces are rejected. Checkpoint and final validation still compare against the original immutable input; `source_repair.json` and the report identify every removed and subdivided source face. Unrepairable degenerates stop before feature recovery instead of wasting repeated attempts.

All operations are enabled by default. Turn off any operation to protect its features from changes, including cleanup. **Circular Holes** detects holes and normally reduces their perimeter segment count. **Preserve Curve Segmentation** is a separate option, off by default. When enabled, it prevents circular-hole, arc and outer-cylinder resampling while leaving selected Perimeter Loops and Background Cleanup available on unchanged contours. It is not an operation by itself: select at least one actual operation. **Arcs** normally reduces concave and convex open arcs. **Outer Cylinders** is a separate choice. **Perimeter Loops** adds square support rings around circular holes and can run by itself on a manually selected earlier hole result. The nearby **Clearance (mm)** field sets the nominal gap between a circular hole radius and the square's nearest side. `0` chooses clearance automatically and may use a wider square to reduce loop vertices. A positive value is fixed in both Auto and Power user: it is never silently increased or decreased. The planner compares rotations and subdivisions, preferring fewer vertices while retaining the triangle-quality and geometry checks. Four or eight vertices are preferred when valid, but tighter fixed gaps can require more. If no support fits at the requested gap, the existing validated direct-join or preserved-feature fallback reports REVIEW. The selected nominal gap is recorded in the run report. Compound cutouts still use their existing separate sizing logic. **Background Cleanup** and **Merge Straight Walls** are separate passes. Every run uses the object or collection the user explicitly chose; both run buttons use the same selected operations, not an automatic chain.

With Preserve Curve Segmentation enabled, the baseline support-ring method is tried even if the circular hole needs no segment reduction. If no safe ring fits but direct joining is valid, the hole is joined directly and the result is marked partial for review. If neither is safe, that feature is preserved and bounded recovery attempts continue with other regions. Every accepted candidate and the final output must pass topology, edge-role, intersection and sampled surface-deviation validation. An unchanged or higher triangle count is not by itself failure: perimeter loops may add triangles, while planar cleanup can remove edges without changing the triangulated count. The report and Results panel show actual created loops, direct joins, skipped holes, removed planar edges and ngon counts. Circular and open-arc sampling uses ordered distinct source vertices and never asks for more segments than the source provides. Retained rim samples keep their source positions.

Generated partial results have a nonempty `CAD_Skipped` vertex group for preserved features, non-manifold patches and unmet perimeter requests. `CAD_Review_Constrained` can mark retained uneven rim samples. These groups never modify the source. `candidate.json` and `vertex_map.json` record explicit source-to-candidate-to-final vertex IDs (`-1` denotes a removed/unmapped vertex); `manifest.json` records exact feature IDs and technical reasons. `REPORT.md` gives a short English explanation and review guidance. If no valid changed mesh exists, `failure.json` and `REPORT.md` explicitly state that no output was created.

CAD reconstruction ignores source custom split normals by default. It uses geometric face normals for planning and regenerates output normals, without changing the source. Authored sharp edges are tracked through explicit vertex maps and retained where possible. Losing a sharp edge is a shading-review warning, not a geometry failure: a geometrically valid changed mesh is marked `PARTIAL / REVIEW`, and the lost source vertex pairs plus any mappable `CAD_Review_SharpEdges` group are reported. Topology, intersection and surface-deviation checks remain mandatory. The Advanced Manual Normal Limit still applies only to straight-wall cleanup.

The worker records the result's world transform in its manifest. Import restores it before parenting so generated geometry remains in the same scene location as its source, including translated/rotated parent hierarchies. An artifact without a valid transform is rejected rather than silently placed at the world origin.

Green `PASS` means all selected operations completed and geometry validation passed, **not** that every CAD detail was identified. Yellow `PARTIAL / REVIEW` means a validated mesh exists but at least one feature or later step was preserved or omitted; inspect `CAD_Skipped` and the report. Red `FAIL` means no validated changed mesh was imported. Visual review remains necessary for every status.

The Reconstruction Options use two-column toggle buttons; hover each for its full explanation. Results start collapsed to short English status lines; expand a row for counts, technical reason and actions. New CAD outputs keep their source object's normal viewport color. **Show** saves the current viewport shading mode and color choices, then switches its Solid/Wireframe color source to Object Color. Material/Rendered preview temporarily changes to Solid. Only generated CAD output objects receive status colors; unrelated object color data never changes. Blender will nevertheless display all scene objects using their existing Object Color while this viewport mode is active. **Hide** restores every viewport where Show was used and restores original CAD output colors. Clear Results and addon unload also restore them.

**Archive & Clear** writes a readable result history to a Blender Text datablock and clears the panel; save the `.blend` to keep that archive. **Clear Results** discards the panel history without an archive. Both keep source meshes, output meshes and run folders. New CAD outputs retain their status on the object, so Show still works after clearing panel history. **Delete Run Files** is a separate, irreversible action for verified CAD worker subfolders directly inside the currently selected Run Folder; it removes source snapshots, reports, logs and intermediate `.blend` artifacts, not scene objects. Its confirmation includes the folder count. If several `.blend` projects share the Run Folder, their verified CAD runs are included. A deleted run loses its Run Files link, although an existing output mesh stays in the scene. All cleanup actions are disabled during a CAD batch.

**Retry** starts a new run. The default normal check uses Blender-topology roundtrip calibration. Advanced Manual Normal Limit accepts any positive finite angle in degrees after risk acknowledgement. Above 0.05 degrees, shading may visibly change. This overrides only the straight-wall corner-normal limit; topology, intersection, deviation, and other geometry checks remain enabled. A higher limit cannot guarantee success. The chosen value is stored in the run profile and report.

## Protected Regions

The collapsed **Protected Regions** section marks faces that every reconstruction must keep exactly as authored. In Edit Mode select faces and use **Protect**; **Unprotect**, **Select** and **Clear** edit or inspect the marking. It is stored as the BOOLEAN face attribute `cad_protected` on the source mesh; geometry is never changed by these tools. Switch back to Object Mode before running.

During a run, every detected feature that shares a vertex with a protected face is left unchanged (`Touches a user-protected region`), protected faces are locked during reconstruction and both cleanup passes, and final validation adds the check `user_protected_preserved`: each protected face must exist in the output with the same vertex cycle at the same (float32) positions. The surrounding flat area may still be re-tessellated around a protected face. Features left as authored because of your protection do not by themselves turn a result into REVIEW. A source without the attribute keeps its previous fingerprint and identical results. Protection also prevents automatic zero-area source repair from touching those faces.

## UV Preparation

The collapsed **UV Preparation** tool is part of the CAD Mesh Reconstruction panel but does not require a CAD run. In Object Mode, select one or more editable mesh objects, set **New UV Map**, optionally adjust **Island Margin** and **Cut Angle (degrees)**, then use **Analyze** or **Generate UV**. Each object gets its own packed 0-1 UV map; existing UV maps, global mesh seams, topology and other attributes remain unchanged. The generated map becomes active for editing while the previous render UV remains the render default. Saving the `.blend` is always manual. Undo reverts the batch.

The geometry planner cuts strong folds and material boundaries, retains smoother bends in larger islands, and gives isolated annular walls a short lengthwise slit. Neither existing seams nor `cad_role` decide the cuts; manually edited CAD outputs and ordinary mesh objects use the same rules. Blender unwrap and packing run on a temporary independent mesh with only the planned working seams. UV-selection synchronization is enabled only during that working step and then restored. The UV values are copied back by verified polygon-loop order, not by nearest-point matching. Temporary objects and meshes are removed after success or failure. If a selected object shares its mesh datablock, the tool first makes that object's data single-user so unselected objects do not gain a UV map. A failed object gets no new UV map and does not stop the rest of the selection.

This is a preparation pass, not a promise of an exact manual layout. Broad sheets usually stay continuous through smooth bends; complex branching folds, irregular cutouts and strong non-developable surfaces can require manual island edits. **Analyze** estimates geometric regions and cuts but cannot guarantee that Blender's unwrap will succeed. Every generated UV must have finite coordinates in 0-1 and nonzero face area. The separate existing UV-channel switch tool can rebuild global seams later if desired; this UV generator never does so automatically.

## Development notes

### Baseline and selectively retained fixes

Commit `9e1befa` is the checkpoint for selective operations and bounded partial recovery; `4939ec2` remains the older behavioral reference. The default reconstruction tries its support-ring perimeter before direct joining. The previous unconditional direct-join shortcut was not retained as the default. Full-circle phase alignment, a no-upsampling segment cap, distinct ordered rim samples with identity aliases, preservation of unchanged rim positions, manifold preflight, explicit vertex provenance and diagnostic groups prevent concrete regressions. Direct joining remains a validated fallback for a clear near-edge hole or an explicit holes-only run. Global auto-weld and speculative feature skipping without a validated shared boundary are not used.

The non-manifold mode is opt-in and uses a distinct topology policy. It closes a protected source-face patch over every feature touching the bad-edge vertices. Reconstruction and cleanup must retain all those face cycles and their Blender-representable local vertex coordinates. Validation compares each original bad edge and its incident faces through explicit source-to-output maps, rejects any new bad edge, open edge, winding error, duplicate, degenerate triangle, intersection or excessive sampled deviation, and retains the usual Euler and perimeter checks. The output is valid **relative to the preserved source defect**, not a manifold mesh. Triangle reduction remains an optimization objective, not a geometry-safety check.

The `cad_mesh_tool` package started as a vendored copy of the user's local CAD Mesh Tool 0.4.1 source (`E:\WORK\00_VIBE\Blender_geo_nodes\cad_mesh_tool`). It also contains integration and geometry fixes maintained in this addon. Keep the bundled worker and API from the same revision: `code_hash()` binds preparation to worker/import. The addon module `cad_reconstruction` owns Scene settings, modal orchestration, placement and UI. The worker executes in a separate Blender process, never a Python thread accessing live `bpy` data.

Distance validation retains the same BVH upper bound, float64 point-triangle calculation, AABB filter and tolerance; since 2026-10-06 sample points are visited in Morton (Z-order) batches of 4096 so neighbouring points share tree nodes. Each point's exact minimum is independent of the visiting order, so every distance value is bitwise unchanged. On an isolated copy of the six-mesh production scene in Blender 5.2.1, one worker took 668.05 s and four workers took 263.85 s (2.53x batch speedup); peak combined worker working set increased from 302 MB to 1123 MB. All six output candidate JSON files were byte-identical between runs, validation checks and statuses matched, and source fingerprints stayed unchanged. `Těleso1.027` produced a validated partial `REVIEW` result with the original non-manifold junction preserved. These are workload-specific measurements, not a guaranteed speedup. A sweep-and-prune intersection prototype produced identical pairs but improved estimated whole-validation time by only 1.9%, 9.5%, and 3.1% on three CAD fixtures, below the 10% adoption threshold, so the original broad phase remains in production. The narrow phase is now evaluated in vectorized blocks of candidate pairs with the same tolerances and predicates (identical pairs on all Collection 1/2 fixtures, 3-8x faster).

Preserve Curve Segmentation is deliberately opt-in. On isolated `Těleso1.027` in Blender 5.2.1, the normal guarded workflow produced `REVIEW` in 212 s with 52 skipped features. With preservation enabled it produced a validated `REVIEW` in 321 s: 0 segments reduced, 50 support loops created, 1,511 planar edges removed, 62 final ngons and 12 skipped features. Both runs left the source fingerprint unchanged. The extra runtime is workload-specific, not a performance promise. The new mode does not attempt a broader patch-transaction rewrite or guarantee that every detected hole receives a loop.

### Performance work 2026-10-06

Measured with an isolated harness on byte-identical Collection 2 snapshots (`.codex/temp/cad_opt_20261006`, Blender 5.2.1, 10 parallel workers). Every change below was accepted only when all outputs stayed identical: plan, candidate, vertex map and perimeter hashes for 27 Power user solids; every Auto variant, winner and candidate hash for the 7 Auto sources.

- Auto computes source intersections, zero-area repair and feature discovery once per solid and hands them to every variant (verified against a digest of the exact `source.json`), instead of up to four times.
- Support-ring placement tests (`contacts`, `inside`) are vectorized with a conservative bounding-box prefilter; identical decisions on 6000 randomized touching/near-touching cases.
- Straight-wall cleanup scans only the edges of each candidate region instead of every mesh edge per region.
- Triangle normals are batched with the unchanged per-face arithmetic.
- Recovery decides by exception **type** (`errors.GeometricConflict`, `errors.StageRejected`) instead of message prefixes; a unit test fails if a recoverable message is raised as a plain `ValueError`.

Not changed on purpose: recovery still tries features in its deterministic order (a bisection search could accept a different set of features and so change results), and every stage is still validated over the whole mesh (local-only validation would weaken the guarantee). Both remain possible future options if their effect on results is accepted.

Known limits: recovery is deterministic and bounded, not a proof of the maximum possible safe subset. A geometry-valid partial result still needs visual inspection and the preserved non-manifold junction must be repaired manually if a manifold mesh is required. The CAD core captures positions, topology, sharp edges and face material indices, but does not currently transfer arbitrary UV, color or custom attribute layers to a reconstructed output. Source custom normals are intentionally not retained. Ordinary workers require closed, consistently wound, intersection-free manifold inputs without unapplied modifiers; automatic guarded workers accept existing non-manifold junctions subject to exact preservation and intersection checks. The guarded contract accepts only pre-existing non-manifold edges in otherwise closed, consistently wound meshes. The extension targets Blender 5.2 LTS (minimum 5.2.0).
